# Upstream reference material

These snapshots supported implementation and API verification. They are not
replacement KOReader modules and are not installed by the plugin.

The KOReader source files retain their upstream license, included in
`koreader-v2026.07.1/COPYING`. The repository's root MIT license does not
relicense these third-party sources. Generated app-server schemas are retained
as interface reference material; their provenance is documented in
`docs/PROVENANCE.md` at the project root.
